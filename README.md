### Compilation Errors

1. **CS1002 — ; expected:** I removed a semicolon from a C# statement, which caused a compilation error. I learned that C# requires semicolons to terminate most statements.

2. **CS0103 — The name 'console' does not exist in the current context:** I changed `Console` to `console`. I learned that C# is case-sensitive and that capitalization matters.

### Integer Division Prediction

My prediction for `250 / 4` using integers was 62, and the actual result was 62 because integer division discards the decimal portion.

The remainder was 2, and converting the value to double produced the exact result of 62.50.
